# Paléo Party

Jeu de plateau façon Mario Party sur le thème du Paléo Festival Nyon, pour Bizu, Benoît XVI et Panoramix.

Pour jouer : ouvrir https://benjaminhermand-max.github.io/Paleo-party/ dans Chrome sur la tablette, puis menu ⋮ → « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
